# Claude Code skills

Two skills that work as a pair.

- **`/algorithm`** — Question → Delete → Simplify → Accelerate → Automate, in order. Decides what should exist. Ends with a Deleted list and a Survived list.
- **`/build`** — Spec → Verifier → Build → Verify → Handoff. Takes the survivors and makes sure they get built correctly, with a verifier designed before any code and evidence for every done-when line.

Install: copy each folder into `~/.claude/skills/`.
